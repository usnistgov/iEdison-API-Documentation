# iEdison API Documentation

Official API documentation for the iEdison system - a web-based platform for managing intellectual property reporting and compliance for federally funded research.

## Overview

This documentation provides comprehensive technical specifications and implementation guides for integrating with the iEdison REST API services. The API enables organizations and agencies to programmatically manage invention disclosures, patent reports, utilization reports, and related documents.

## What's Included

- **Invention API** - Create, update, and search invention records
- **Patent API** - Manage patent applications and filings
- **Utilization API** - Submit and track commercialization reports
- **Document API** - Search and download supporting documents
- **Notification API** - Retrieve pending notifications
- **Code Samples** - Working examples in multiple languages
- **Lookup Values** - Reference data and enumeration values
